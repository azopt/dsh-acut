# ACut

**Screenshot plugin for DeepSeek Harness** (`dsh-acut`): press **Ctrl+Shift+X**, drag a region,
annotate it, or stitch a scrolling page into one long image — and the same capture engine is
exposed to the agent as the `screenshot` tool.

截图插件：**Ctrl+Shift+X** 唤起、拖出选区、随手标注、滚屏截成一张长图；同一套抓屏引擎还作为
`screenshot` 工具交给 Agent 用。

```
┌─────────────────────────────────────────────┐
│ 冻结画面（截图瞬间整窗定格）                  │
│   ┌── 选区 ──────────────┐                   │
│   │  标注画在这块画布上    │                   │
│   └──────────────────────┘                   │
│        [矩形 椭圆 箭头 画笔 文字 马赛克]      │
│        [颜色×4] [撤销] [长截图] [重截] [×] [完成] │
└─────────────────────────────────────────────┘
```

## 安装

```sh
dsh plugin --profile <你的 profile> add dsh-acut
```

也可以在 DSH 插件市场里一键安装。插件行配置可选，全部省略也能跑。

## 功能

| 能力 | 说明 |
| --- | --- |
| 热键唤起 | `Ctrl+Shift+X`（macOS `⌘+Shift+X`），在任意 Harness 页面按下即可 |
| 冻结帧 | 先抓屏再画遮罩，所以遮罩自己永远不会进入截图 |
| 选区 | 拖动创建、八向手柄调整大小、实时尺寸角标 |
| 标注 | 矩形、椭圆、箭头、画笔、文字、马赛克；四种颜色；撤销 |
| 滚动截图 | 拉出选区后点 **「↕ 滚动截图」**（或按 `S`）：页面保持可见、虚线框常驻，**你自己滚**——滚轮、触控板、拖滚动条、按住鼠标拖内容都行，上下左右都能拼；进度条实时显示「N 帧 · 宽×高」，旁边还有个 **悬浮小窗**实时预览（整张图等比缩进卡片，长图会变成一条细长条，但能看全貌）；按 `完成`/`Enter` **直接保存长图并复制到剪贴板**（不经过标注界面），也可以直接按 `钉住` 把它贴到屏幕上 |
| 另存为 | 工具栏 **「另存为」**：弹系统保存对话框自己挑位置（默认那份仍然照常自动保存） |
| 钉住 | 工具栏 **「钉住」**：把这张图贴成**无边框、置顶**的小窗口浮在桌面上，可以边看边操作别的窗口。拖动移动，鼠标移上去出「复制 / 另存为 / 关闭」，双击或 Esc 关闭 |
| 交付 | `Enter`/「完成」= 存 PNG 并复制到剪贴板；路径显示在提示条里 |
| 滚动截图的框 | 抓帧比选区各边内缩 12px，虚线框画在选区外沿，所以虚线永远不会被拼进长图 |
| Agent 工具 | `screenshot`：`list` / `screen` / `window` / `scroll` / `diag`，截图落盘并贴回对话 |

保存目录默认 `%USERPROFILE%\Pictures\DSH Screenshots`，可在插件行配置里改 `outputDir`。

## 两种抓屏后端

| 宿主 | 冻结帧 / 窗口 | 滚屏 |
| --- | --- | --- |
| Desktop（Host 里能拿到 Electron API） | `webContents.capturePage`：纯页面内容、无窗口装饰 | 滚动页面内的滚动容器逐帧抓取，结束还原滚动位置 |
| 其它宿主（Windows） | PowerShell + GDI 抓窗口所在的屏幕区域，按窗口装饰偏移对齐 | 滚轮推进目标窗口逐帧抓屏（先向下；到底了自动改向上），拼接后滚回原处 |

非 Windows 且没有 Electron 时，接口会明确报"抓不到屏幕"，不会交回黑图。

## 拼接原理

相邻两帧重叠区像素一致，`src/image.js` 在候选位移里先用抽样行粗搜、再在最优解附近
逐行精搜，取误差最小的重叠量把新内容接上去；误差超阈值就整帧追加。
PNG 编解码自带（`src/png.js`，zlib + 手写反滤波），所以没有额外依赖。

## 配置（`cordis.patch.yml` 的行配置，都可省略）

| 字段 | 默认 | 含义 |
| --- | --- | --- |
| `outputDir` | `~/Pictures/DSH Screenshots` | 截图落盘目录 |
| `frames` | 桌面滚屏帧数上限 | 见 `src/index.js` |
| `delayMs` | 每帧间隔 | 页面滚动后等多久再抓 |
| `chromeOffsetX` / `chromeOffsetY` | 自动推算 | 窗口装饰到内容区的偏移，屏幕抓取时用 |

## 已知限制

- 热键固定为 `Ctrl+Shift+X`，还没接进 Harness 的快捷键面板。
- 滚动截图依赖页面本身能滚动；会话正在流式输出时视图会被钉在底部，这时会一直停在
  "滚一下开始拼接"——等这一轮跑完再截即可。无限列表、懒加载内容可能拼不全。
- 滚动截图会吞掉鼠标点击（避免误触页面按钮），但滚轮和拖动都交给你自己控制。
- 选区里如果包进了不跟着滚的家具（左侧栏、输入框），拼接时那几列会在每一段重复出现；
  只框住真正滚动的内容列最干净。
- 长图上限：400 帧 / 30000px 高（触顶时进度条会写「已达上限」）。
- 桌面模式滚屏会把鼠标移到选区中心滚轮，结束后还原位置；期间不要动鼠标。
- 冻结帧只覆盖本窗口；要抓别的程序请用 Agent 工具的 `screen`。

## 语言：跟随系统

界面语言**跟着系统语言走**，不用配置：

| 系统语言 | 界面 |
| --- | --- |
| 简体中文 | 中文（源码里的原文） |
| 繁體中文（台灣/香港/澳門） | 繁體中文 |
| English | English |
| 日本語 | 日本語 |
| 한국어 | 한국어 |
| Deutsch | Deutsch |
| Français | Français |
| Español | Español |
| Русский | Русский |
| Português | Português |

列表外的语言退回英文。想钉死某一门，在插件配置里写 `language`（默认 `auto`）：

```yaml
- insert:
    - id: acut
      name: 'dsh-acut'
      config:
        language: ja     # auto | zh | zh-Hant | en | ja | ko | de | fr | es | ru | pt
```

解析顺序：插件配置 → Electron 的系统语言 → 系统 ICU 区域 → `en`。
